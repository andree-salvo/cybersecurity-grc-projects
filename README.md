# Cybersecurity Governance, Risk, and Compliance (GRC) Projects

## About This Repository

This repository contains hands-on projects I've worked on to build my skills in Governance, Risk, and Compliance (GRC), cybersecurity risk management, security policies, and compliance frameworks.

For these projects, I'm using a fictional healthcare company called **MedBridge Health, Inc.**, based in San Francisco, California.

Through these projects, I'm gaining practical experience identifying security risks, assessing security controls, documenting findings, and recommending improvements to help organizations protect sensitive information and meet compliance requirements.

## Frameworks and Standards

Throughout these projects, I'll be working with the following cybersecurity frameworks and standards:

- **NIST Cybersecurity Framework (CSF) 2.0**
- **NIST SP 800-53**
- **HIPAA Security Rule**
- **CIS Critical Security Controls**
- **ISO/IEC 27001**
- **SOC 2 Trust Services Criteria**

## Portfolio Objectives

My goal with this portfolio is to gain more hands-on experience with GRC by working through realistic cybersecurity and compliance scenarios.

I want to improve my ability to identify potential security risks, understand how different cybersecurity frameworks are used, and document findings in a way that is clear and easy to understand.

These projects also give me an opportunity to practice developing security documentation and making recommendations based on identified risks.

## Project Environment

**MedBridge Health, Inc.** is a fictional healthcare organization created for this portfolio.

| Category | Details |
|---|---|
| Headquarters | San Francisco, California |
| Industry | Healthcare / Telehealth |
| Employees | 50 |
| Active Patients | Approximately 40,000 |
| Cloud Infrastructure | Amazon Web Services (AWS) |
| Identity Management | Okta |
| Compliance Considerations | HIPAA, HITECH, applicable state privacy laws |
| Business Objective | SOC 2 Type II report within 12 months |

Projects 1–5 use this fictional company to demonstrate different GRC activities. Project 6 focuses on an authorized home network security audit.

## Disclaimer

All company information, security findings, and business scenarios involving MedBridge Health are fictional and created for educational purposes.

This portfolio documents simulated GRC assessments and recommendations and does not represent an audit of a real healthcare organization.
