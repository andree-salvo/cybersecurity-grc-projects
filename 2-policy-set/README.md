# Project 2: Core Security Policies

## Objective

The goal of this project is to develop security policies for MedBridge Health, Inc., a fictional healthcare company based in San Francisco, California.

I'll be focusing on creating policies that address the company's security risks, protect sensitive patient information, and help support its cybersecurity and compliance requirements.

## Project Scope

For this project, I'll be developing four security policies:

1. Information Security Policy
2. Acceptable Use Policy
3. Password and Authentication Policy
4. Incident Response Policy

Each policy will be based on security best practices and tailored to MedBridge Health's environment.

## Frameworks and Standards

- HIPAA Security Rule
- NIST Cybersecurity Framework (CSF) 2.0
- NIST SP 800-63B
- ISO/IEC 27001:2022
- SANS Security Policy Templates

## Tools Used

- GitHub
- Microsoft Word / Google Docs
- SANS Security Policy Templates

## Approach

1. Review security policy templates and relevant security standards.
2. Identify policy requirements based on MedBridge Health's business operations and security weaknesses.
3. Develop four security policies tailored to the company.
4. Define employee responsibilities and security requirements.
5. Document policy changes and explain why they were made.
6. Review and export the completed policies as PDF files.

## Deliverables

- Information Security Policy
- Acceptable Use Policy
- Password and Authentication Policy
- Incident Response Policy
- Policy Tailoring Log
