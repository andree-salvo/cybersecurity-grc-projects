# NIST CSF 2.0 Cybersecurity Assessment

## Project Overview

For this project, I'm conducting a simulated cybersecurity assessment of **MedBridge Health, Inc.**, a fictional telehealth company based in San Francisco, California, using the NIST Cybersecurity Framework (CSF) 2.0.

The goal is to evaluate the company's current cybersecurity practices, identify gaps, and recommend improvements to strengthen its overall security posture.

This project builds on the company profile, security policies, and cybersecurity risk assessment completed in my previous GRC projects.

## Project Objectives

- Evaluate cybersecurity practices against the six NIST CSF 2.0 functions.
- Develop a Current State Profile based on documented security practices.
- Establish a Target State Profile for recommended security improvements.
- Identify gaps between current and target cybersecurity capabilities.
- Prioritize improvement opportunities based on cybersecurity risks.
- Develop a remediation roadmap with recommended actions and responsible owners.

## Framework

**NIST Cybersecurity Framework (CSF) 2.0**

The assessment covers the six core functions:

1. **Govern (GV):** Cybersecurity policies, strategy, risk management, and oversight.
2. **Identify (ID):** Asset management, risk assessment, and cybersecurity risk awareness.
3. **Protect (PR):** Identity management, security awareness, data protection, and platform security.
4. **Detect (DE):** Continuous monitoring and analysis of security events.
5. **Respond (RS):** Incident management, analysis, reporting, and mitigation.
6. **Recover (RC):** Recovery planning, communication, and restoration of affected systems.

## Assessment Methodology

I will review MedBridge Health's documented security practices and compare them against relevant NIST CSF 2.0 outcomes.

For each selected outcome, I will document the available evidence, describe the current state, define the target state, and identify any gaps.

The assessment will focus on practical improvements that MedBridge Health could make based on its size, technology environment, and identified cybersecurity risks.

Draft policies and proposed controls will not be treated as fully implemented without supporting evidence.
